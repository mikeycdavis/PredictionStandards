## What

`scripts/submit-pr.mjs`: refuse a dirty tree, record `HEAD`, run the pipeline, re-check `HEAD`,
then push the **SHA** rather than the branch.

## Why

Running CI and then pushing is not the same as pushing what CI verified.

## Notes

The predicates are pure and exported, and `test/local-ci.test.mjs` pins them **inside the pipeline
this script runs** — so the guard is tested by the thing it guards. `gh` uses the developer's own
authenticated session; no token is read, written or stored by this repository.
