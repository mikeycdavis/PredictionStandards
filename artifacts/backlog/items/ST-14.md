## What

Move the stage list into `package.json`'s `ci.stages`, run it from `scripts/ci.mjs`, and reduce the
workflow to invoking that.

## Why

The workflow spelled out one `run:` per check, which reads better in the Actions UI and made the
file a second definition of the pipeline.

## Notes

`npm test` could not have run on the Node version CI declared: the command was
`node --test "test/*.test.mjs"`, and runner-resolved globs arrived after Node 20. It passed only on
a developer machine running Node 24 — a check reporting on the environment it happened to find
rather than the one the repository claims.
