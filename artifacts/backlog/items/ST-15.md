## What

Run the checks inside a digest-pinned `node:20-alpine` container that cannot write to the tree and
has no network.

## Why

A pipeline that can modify the tree it is checking can make itself pass. The isolation is what lets
a local run mean the same thing as a hosted one.

## Notes

No personal token, SSH credential or Docker socket is exposed to the container, and no production
credential exists in the repository to expose.
