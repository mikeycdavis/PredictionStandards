## What

Implementation of exactly the candidate set the evidence review accepted, in the order C1, then
C2, then the arithmetic and reconciliation corrections, then documentation — with the full
gauntlet run between groups.

## Why

An ordered implementation makes the release-defining change (C2) land against a verified
baseline, and makes any regression attributable to a known group.

## Notes

No eleventh candidate was added during implementation. The only admissible reason to reopen the
set would have been implementation proving a disposition internally inconsistent, and none did.
