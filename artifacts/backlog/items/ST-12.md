## What

Remove stale EngineeringStandards-specific standard numbers and names left behind when this pack
was ported from that one — for example a comment citing "Standard 24 R2", which is not a
standard in this pack.

## Why

something that was never in this repository.

## Notes

Classified as **reference-port cleanup — not a PredictionStandards defect and not a v1.1
feature.** The distinction matters: the code was correct; only its citation pointed at the wrong
document.

The whole repository was searched for other stale standard numbers and names before any single
one was changed. Fixing the one that happened to be noticed would have left the class intact and
made the next occurrence look like a new discovery.
